🔗 Adjacency List (Direct Connections)

The Adjacency List is the data structure used to represent the graph in memory. For each location, it shows which other locations are directly reachable in one step. Space complexity: O(V + E) = O(5 + 5) = O(10).

📊 Complexity Analysis

BFS Time

O(V + E)

Each vertex is enqueued/dequeued once (O(V)). Each edge is checked once (O(E)). Total = O(V+E) = O(10).

DFS Time

O(V + E)

Each vertex is visited once (O(V)). Each edge is explored once (O(E)). Total = O(V+E) = O(10).

BFS Space

O(V)

Queue holds at most V vertices. Visited[] and parent[] arrays are each size V. Total = O(V) = O(5).

DFS Space

O(V)

Visited[] array = O(V). Recursion call stack depth ≤ V levels in worst case. Total = O(V) = O(5).

Graph Build

O(V + E)

Initialising V adjacency lists + inserting E edges. Each edge insertion is O(1) (prepend). Total = O(V+E).

Route Reconstruction

O(L)

Trace parent[] array from destination back to source. L = number of vertices in the path. L ≤ V.

🔵 BFS — Breadth First Search

  • Explores locations level-by-level (1 hop, then 2 hops, …)
  • Uses a Queue (FIFO) data structure
  • Guarantees the path with the fewest hops in an unweighted graph
  • Does NOT guarantee shortest physical distance (corridors may differ in length)
  • Visits all locations at distance d before visiting any at d+1
  • Good for: route finding, shortest-hop navigation

🟣 DFS — Depth First Search

  • Explores as deep as possible along each path before backtracking
  • Uses Recursion (implicit call stack)
  • Does NOT guarantee any shortest path
  • Useful for checking if all locations are reachable (connectivity)
  • Backtracks when a dead-end (no unvisited neighbors) is reached
  • Good for: exploring all reachable areas, cycle detection
For This Project (V=5, E=5)
BFS Time = O(V+E) = O(5+5) = O(10) ≈ constant
DFS Time = O(V+E) = O(5+5) = O(10) ≈ constant
BFS Space = O(V) = O(5) = O(5) ≈ constant
DFS Space = O(V) = O(5) = O(5) ≈ constant
Adjacency List (graph) = O(V+E) = O(10) memory cells
